# Dosezy v2.3.0 Implementation & Feature Roadmap Plan

## Overview
Dosezy v2.3.0 is a major feature upgrade focusing on **Slot-Based Grouped Alarms**, **Multiple Daily Dosing Presets**, **Home Medicine Inventory & Stock Tracking**, **OpenAPI 3.0 Sync**, and **Full Localization (12 Languages)**.

---

## Technical Objectives

### 1. Grouped Alarms (Time-Slot Alarm Batching)
- **Problem:** Taking multiple medicines at the same scheduled time (e.g., 5 tablets at 8:00 AM) previously triggered multiple separate alarms and clashing full-screen activities.
- **Solution:** Batch alarms by `(userId, scheduledDateTime)` slot.
- **Implementation:**
  - Update `AlarmScheduler.kt` to schedule 1 alarm per distinct time slot.
  - Update `MedicineAlarmReceiver.kt` to send array extras (`EXTRA_ENTRY_IDS`, `EXTRA_MEDICINE_NAMES`).
  - Update `AlarmActivity.kt` to render a grouped checklist UI with a single **"Take All"** action.

### 2. Multi-Dose Quick Presets
- **Implementation:**
  - Add quick frequency chips in `AddMedScreen.kt` for `1x Daily`, `2x Daily`, `3x Daily`, and `4x Daily`.
  - Automatically populate standard default time chips (`08:00`, `14:00`, `20:00`, etc.) while retaining manual time picker customization.

### 3. Home Inventory & Stock Tracking
- **Database Schema (Room Migration 15 -> 16):**
  - Add `currentStock: Int? = null`, `refillThreshold: Int? = null`, `autoDeductOnTake: Boolean = true` to `medicines` table.
  - Implement `Migration(15, 16)` in `DosezyDatabase.kt`.
- **Business Logic:**
  - Automatically decrement `currentStock` when dose is marked `TAKEN`.
  - Trigger a low-stock alert when `currentStock <= refillThreshold`.
- **UI Integrations:**
  - Inventory input fields in `AddMedScreen.kt`.
  - Stock badges and refill warning alerts on `HomeScreen.kt` and `ScheduleScreen.kt`.

### 4. Version & Metadata Synchronization (v2.3.0 / versionCode 16)
- **Build Gradle:** Update `versionName = "2.3.0"`, `versionCode = 16`.
- **Fastlane Changelogs:** Create `2.3.0.txt` in root `fastlane/` and `patient/android/app/fastlane/`.
- **Localization:** Update string keys across all 12 `res/values-*/strings.xml` files.
- **Documentation & Website:** Update `README.md`, `UserManual.md`, `FAQ.md`, `openapi.yaml`, and website content replacing `v2.2.2` with `v2.3.0`.
