# `v2.4.2`

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2 transitions to our official production release signing key (required for Google Play), Android will require a clean reinstall:
> 1. In Dosezy, go to **Menu → Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.4.2** APK.
> 4. Go to **Menu → Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

---

## 💊 Patient App (Android)

* **Target API 36 (Android 16) & NDK Debug Symbols**:
  - Upgraded target and compile SDK to API level 36 satisfying latest Google Play Store security and platform requirements.
  - Added full NDK debug symbol generation in App Bundle packaging for crash reporting and diagnostics.
* **Production Release Signing**:
  - Configured permanent production keystore signing for Google Play and GitHub release distribution.
* **Archive Security Hardening (Zip Slip / CWE-22)**:
  - Enhanced zip backup extraction in `BackupRestoreManager` using normalized path verification and directory traversal entry validation.
