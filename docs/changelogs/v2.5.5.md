# `v2.5.5`

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu → Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.5.5** APK.
> 4. Go to **Menu → Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

---

## 📱 Patient App (Android)

* **Critical Storage Exhaustion Protection**: Implemented real-time storage checks (`StorageUtils`) on application launch and resume. When internal storage is critically low (<25 MB) or completely exhausted (0 bytes), a high-visibility `LowStorageDialog` alerts the patient before SQLite transactions or background write operations fail with `SQLiteFullException`, providing a 1-tap shortcut directly to Android Storage Settings to clear space.
* **12-Language Storage Alert Translations**: Added native translations for storage warning titles, descriptions, and action buttons across all supported locales: English, Arabic, Bengali, German, Spanish, French, Hindi, Italian, Japanese, Portuguese, Russian, and Chinese.
* **Massive Unit Test Suite Expansion (214 Tests)**: Expanded test coverage across the highest-value core logic layers with a 100% JVM pass rate:
  * **ViewModel State Flows**: Reactive unit tests for `ScheduleViewModel` and `MedicineViewModel` verifying dose marking, late states, undo actions, date filtering, and user profile switching.
  * **In-Memory Room SQLite Database Tests**: Validated date-range queries, UTC epoch millis boundaries, `@Transaction ScheduleWithMedicine` joins, and SQLite foreign key cascading deletes (`ON DELETE CASCADE`).
  * **Backup & Restore Validation**: Tested backward-compatibility parsing of legacy backup payloads, corrupted date/time string resilience, and zip path traversal security defenses (Zip Slip).

## 🔌 API & Shared Data Contracts
