# `v2.4.6`

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu → Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.4.6** APK.
> 4. Go to **Menu → Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

---

## 💊 Patient App (Android)

* **Chronological Schedule Ordering**:
  - Enforced strict chronological sorting (`ORDER BY scheduledDateTime ASC`) on SQLite Room database queries for daily schedule and calendar views so medicines always appear in sequential morning-to-night order.
* **F-Droid Build Compliance**:
  - Refined release build type signing configuration to cleanly default to `null` (unsigned APK) when `keystore.properties` is absent, removing the need for `sed` preprocessing on F-Droid builders.
