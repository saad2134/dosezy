# `v2.5.0`

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu → Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.5.0** APK.
> 4. Go to **Menu → Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

## 💊 Patient App (Android)

* **Alarm & Notification Reliability Overhaul**:
  - **Dynamic Snooze Duration**: Alarm popups, heads-up notifications (HUN), and background receivers now dynamically respect the user's custom snooze preference (5, 10, 15, 20, 30 min) instead of hardcoding 10 minutes.
  - **Notification Reliability Dialog**: Streamlined system diagnostics with combined exact alarm guidance, intelligent warning states, and direct OEM background setting navigation (Samsung, Xiaomi, etc.).
  - **100% Alarm & Home Localization**: Replaced all hardcoded English strings on full-screen alarms, heads-up notification buttons, medication cards ("Take", "Taken", "Mark Late", "Missed"), and frequency dropdowns across all 12 supported languages.
  - **Intake Undo Snackbar**: Added a transient 5-second action Snackbar with "Undo" when marking doses taken, automatically reverting dose status and safely restoring auto-decremented inventory.

* **Medication & Schedule Management**:
  - **Completion Banner & Full Daily Review**: Replaced full-screen takeover on `HomeScreen` with a celebratory `AllGoodBanner` pinned at the top when all doses are taken, keeping the entire day's schedule visible with interactive card buttons to review or undo taken doses.
  - **Medicines Search & Empty State CTA**: Added an instant real-time search and filter bar to `MedicinesScreen` allowing rapid searching across large rosters, plus an explicit "Add Your First Medication" primary CTA on empty medication lists.
  - **Safe Archived Medicine Editing**: Resolved a crash (`NullPointerException`) when opening or discontinuing archived medications in `EditMedScreen` by searching across active and archived rosters and safeguarding deletions.
  - **Form Validation Feedback**: Replaced silent button gray-outs in Add/Edit Medication with helpful validation guidance when required fields (medicine name, dosage, weekly/monthly days) are incomplete.
  - **Strict Chronological Ordering**: Enforced chronological ordering (`ORDER BY scheduledDateTime ASC`) on daily and calendar schedule queries so doses appear in sequential morning-to-night sequence.

* **Profiles & Emergency Contacts**:
  - **Multi-Profile Emergency Contacts**: Namespaced emergency contacts per user profile in private preferences (`contacts_json_<userId>`), preventing profile data leakage in multi-user households.
  - **Emergency Backup Integration**: Included emergency contacts directly in the backup ZIP archive, ensuring full restoration during phone migrations.
  - **Profile Switcher Polish**: Tapping the currently active profile now smoothly returns to the previous screen instead of failing silently.

* **Onboarding & Visual Polish**:
  - **Compact Subscreen TopBar**: Collapsed subscreen headers into a sleek single-row TopAppBar, conserving 50%+ vertical screen space while preserving the vital Notification Reliability Status button and custom actions.
  - **Wizard Navigation Clarity**: Corrected secondary navigation buttons on frames 2 & 3 of onboarding from "Cancel" to "Back".
  - **Dark Mode Consistency**: Harmonized onboarding secondary buttons with Material3 surface variants, eliminating bright white blocks in dark mode.
  - **Analytics Empty State**: Added an encouraging, informative empty state card for new profiles explaining adherence metrics.
  - **Preferences & Menu Reorganization**: Reorganized the Preferences screen into clean, structured sections (General, Notifications & Alarms, Dose Tracking) with native subheadings across all 12 languages; added a dedicated "More" section to MenuScreen.

* **Lifecycle & Performance Fixes**:
  - **Schedule Calendar Date-Tap Optimization**: Deduplicated date change queries and cached monthly calendar indicator dots, eliminating rapid skeleton loader flashing when switching days.
  - **Cold-Start Home Screen Glitch**: Added a smooth loading gateway destination in `MainActivity.kt`, eliminating the brief flash of an empty home screen on fresh installs before routing to setup.

* **F-Droid Build Compliance**:
  - Refined release build signing configuration to cleanly default to `null` (unsigned APK) when `keystore.properties` is absent, removing the need for `sed` preprocessing on F-Droid builders.
