# v2.5.14: Pharmacy Refill Order Stock Unit Precision

## Summary of Changes
Release v2.5.14 resolves a medication inventory display discrepancy in pharmacy refill orders where current stock was displayed with dosage strength units (such as "mg") rather than countable inventory units.

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu -> Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.5.14** APK.
> 4. Go to **Menu -> Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

---

## 📱 Patient App (Android)

* **Pharmacy Refill Order Stock Unit Precision (#129)**:
  - Corrected pharmacy refill orders and the in-app order dialog to display current inventory stock in countable units (`units`, `bottles`, `tablets`, `capsules`) rather than chemical dosage strengths (`mg`, `mcg`, `mEq`).
  - Centralized stock and order unit formatting in `DosageFormatUtils`, ensuring full consistency across clipboard copy, chat sharing, and dialog previews across all 12 supported locales.
