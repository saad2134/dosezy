# v2.5.14: Rolling Intake Intervals, Pharmacy Custom Days, and Stock Unit Precision

## Summary of Changes
Release v2.5.14 introduces dynamic rolling intake intervals from actual medication intake times, flexible custom supply duration options for pharmacy refill orders, and resolves a medication inventory display discrepancy where current stock was displayed with dosage strength units rather than countable inventory units.

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu -> Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.5.14** APK.
> 4. Go to **Menu -> Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

## 📱 Patient App (Android)

* **Dynamic Rolling Intake Intervals from Medication Taken (#119)**:
  - Added support for rolling intake intervals: when a dose is taken late (or early), future pending doses and alarms automatically re-anchor from the actual intake time plus the prescribed interval (e.g. `takenAt + interval`), preserving safe therapeutic spacing and preventing dangerous dose stacking.
  - Symmetrical undo support: undoing a taken dose automatically purges re-anchored entries and restores the original baseline schedule and alarms.
  - Frequency configuration toggle available for daily, hourly, and multi-day regimens in both Add and Edit medication forms.
  - Seamless backup export and import preservation across JSON backups.
  - Full localization parity across all 12 supported app languages.

* **Custom Supply Days for Pharmacy Refill Orders (#128)**:
  - Added support for custom integer supply durations (such as 7, 14, 21, 28, 42, 56 days) in the Pharmacy Refill Order dialog alongside the standard presets (15, 30, 60, 90 days).
  - Integrated an interactive custom days input with quick increment and decrement steppers, real-time quantity recalculation, and squircle design geometry.
  - Added localized strings across all 12 supported app languages.

* **Pharmacy Refill Order Stock Unit Precision (#129)**:
  - Corrected pharmacy refill orders and the in-app order dialog to display current inventory stock in countable units (`units`, `bottles`, `tablets`, `capsules`) rather than chemical dosage strengths (`mg`, `mcg`, `mEq`).
  - Centralized stock and order unit formatting in `DosageFormatUtils`, ensuring full consistency across clipboard copy, chat sharing, and dialog previews across all 12 supported locales.
