# `v2.5.2`

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu → Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.5.2** APK.
> 4. Go to **Menu → Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

## 💊 Patient App (Android)

* **Crossing Time Zones ("Doses Shift With You")**: When traveling across time zones, Dosezy ensures your medication schedule remains pinned to your local wall-clock daily routine (e.g., 8:00 AM stays 8:00 AM) without time distortion. Device timezone change events automatically reschedule all alarms and update home screen widgets for your new destination.
* **Manually Record Dose Time**: Added an optional preference under **Menu → Preferences** allowing patients to log the exact time they took a medication when recording doses later. Features interactive choices ("Just Now", "Scheduled Time", or custom time picker) and accurately computes on-time vs. late adherence based on the recorded timestamp while preserving 1-tap logging when disabled.
* **Navigation Customization & Roster Add Button**: Added an option in **Preferences → General** to hide the center "+" add button on the bottom navigation bar. When active, navigation tabs smoothly redistribute symmetrically, and a prominent "Add Medicine" button is conveniently placed at the bottom of the Medicines screen below current medications.
* **Enhanced Pharmacy Refill Orders**: Multi-profile consolidation allows caregivers to combine refills across multiple family members into one order; smart bottle calculations convert eye drops and liquid doses into practical bottle quantities (with a default 100 drops per bottle packaging baseline); and the streamlined format features cleaner headers, no redundant dose clutter, and selectable text preview for easy copying.
* **Expanded About Page, Profile Deletion Text Fix**: Revamped the About screen with core pillars and developer profile, and fixed confirmation button text in profile deletion dialog.
* **Database Migration (v11 → v13)**: Seamless Room database migrations supporting `allowCustomDoseTime` (v12) and `hideAddMedicineNavButton` (v13).
* **Full 12-Language Translations**: Added complete native translations for all new preferences, dialogs, about pillars, and pharmacy refill features across all 12 supported locales.
