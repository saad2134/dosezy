# `v2.5.4`

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu → Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.5.4** APK.
> 4. Go to **Menu → Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

## 📱 Patient App (Android)

* **Device Navigation Bar Inset Handling**: Fixed an issue on Android 15 devices (including Pixel 8a and Redmi) with 3-button navigation enabled where the system Back, Home, and Recents buttons overlaid the bottom navigation bar, preventing interaction with Home, Schedule, and Add Medicine buttons. `CustomNavigationBar` now dynamically applies navigation bar window insets, lifting interactive buttons cleanly above device navigation controls while extending surface styling to the bottom edge.
* **Alarm Reliability and Exact Alarms**: Declared `USE_EXACT_ALARM` permission in the app manifest to guarantee pre-granted exact alarm scheduling on Android 13+ and Android 14/15 Doze modes, added automatic startup exact alarm verification, and enabled `android:exported="true"` on `MedicineAlarmReceiver` so scheduled alarms are reliably restored after overnight device reboots.
* **Dedicated Exact Alarm Reliability Status**: Added a dedicated "Exact Alarms" diagnostic item in the Notification Reliability shield popup, ensuring missing alarm scheduling permissions turn the topbar status icon red and provide a 1-tap shortcut directly to Android Alarms and Reminders settings.
* **Top Bar Inset Gap Elimination**: Resolved an issue where screens with nested scaffold layouts (`HomeScreen`, `Add Medicine`, `Edit Medicine`, `Preferences`, `Manage Profile`, `Switch Profile`, `Analytics`) exhibited an awkward empty gap above the top header bar due to unconsumed status bar insets. Insets are now consumed at the navigation host level and explicitly neutralized on inner scaffolds, providing flush and uniform header alignment across all screens.
* **Unified Edge-to-Edge Support**: Explicitly adopted `enableEdgeToEdge()` in `MainActivity` with synchronized status bar and navigation bar contrast controllers, ensuring uniform, modern UI behavior across Android 10 through Android 15 and 16 on Samsung, Google Pixel, Xiaomi, and other manufacturer devices.
* **Full-Screen Alarm Safe Insets**: Added safe drawing insets padding to `AlarmActivity` to protect reminders, profile information, and emergency actions from being clipped by display cutouts or system navigation bars.
