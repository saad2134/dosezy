# v2.5.13: Custom Sorting, Fractional Doses, and Multi-Profile Alarm Coordination

## Summary of Changes
Release v2.5.13 brings custom medication reordering and sorting presets, full support for half and fractional medication dosages with precise inventory synchronization, isolated multi-profile alarm and snooze routing, continuous nagging reminders, atomic as-needed (PRN) dose transactions, an executive squircle UI frame design overhaul across all screens, and enhanced PDF export formatting.

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu -> Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.5.13** APK.
> 4. Go to **Menu -> Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

## 📱 Patient App (Android)

* **Medicine Sorting Presets and Custom Reordering (#120)**:
  - Implemented interactive medication sorting on the Home and Medicines screens, supporting Schedule/Default, Alphabetical (A-Z), Next Due, Recently Added, and Custom drag-and-drop reordering.
  - Preserved custom user order index across backup export and restore operations.
  - Synchronized custom sorting order with home screen quick-actions and glance app widgets.
* **Half and Fractional Dosages for Regimens and Inventory (#123)**:
  - Enabled support for half and fractional dose quantities (such as 0.5 tablet, 1.5 pills, or 0.25 doses) across medication creation, schedule setup, and dose intake.
  - Updated inventory depletion calculations and low-stock alerts to accurately decrement fractional quantities.
  - Formatted dose displays to automatically trim redundant trailing zeros for clean presentation.
* **Multi-Profile Alarm, Snooze, and Notification Routing**:
  - Fully isolated alarm broadcasts and notification drawer actions (`Take`, `Snooze`, `Skip`) per user profile to eliminate cross-profile interference.
  - Implemented grouped snooze persistence and user forwarding (`snooze_group_user_$primaryId`) to ensure multi-dose alarms ring for the correct patient profile.
  - Resolved fallback active user resolution in background alarm broadcast receivers.
* **Continuous Nagging Repeat Reminders and Sub-Hour Granularity**:
  - Added configurable nagging repeat reminders (every 5, 10, or 15 minutes) until pending medication is taken or explicitly dismissed.
  - Introduced granular sub-hour options for late and missed medication alerts.
* **ADHD Intake Safeguard and Room PRN Transaction Safety**:
  - Enforced profile-level lock screen masking (`lockscreenDetailsEnabled`) inside `IntakeSafeguardManager` to protect sensitive drug names on lock screens.
  - Wrapped `logAsNeededDose` within Room `database.withTransaction` to guarantee atomic medicine creation, stock decrement, and history entry logging.
  - Cleaned up intake safeguard state upon user profile deletion to prevent phantom alert resurrection.
* **Universal Squircle Frame Geometry and UI Modernization**:
  - Refactored all UI frames, buttons, avatar placeholders, icon containers, action chips, dialog headers, and status badges across 20 Jetpack Compose components to squircle geometry (`RoundedCornerShape`).
  - Added official vector brand icons with theme-aware tints for community and support links in the About screen.
  - Updated build flavor badges to "Marketplace Build" and "FOSS Build" across all 12 supported languages.
* **Export Formatting, Diagnostics, and Performance Optimizations**:
  - Fixed CJK multi-line text wrapping and multi-page table header formatting in clinical PDF export reports.
  - Added dynamic bitmap downsampling for medication photo attachments to eliminate potential out-of-memory errors.
  - Optimized R8 ProGuard rules to reduce overall APK and DEX binary footprint.
