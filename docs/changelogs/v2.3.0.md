# `v2.3.0`

## 💊 Patient App (Android)

* **Slot-Based Grouped Alarms**: When multiple medicines are scheduled at the exact same minute (e.g., 5 tablets at 08:00 AM), Dosezy groups them into a single non-clashing alert. The full-screen `AlarmActivity` displays an interactive checklist where users can mark off individual medicines or tap **"TAKE ALL"** with a single action.
* **Exact Minute Slot Truncation**: Explicitly truncated seconds and nanoseconds (`withSecond(0).withNano(0)`) across database models, time pickers, and alarm schedulers to guarantee that all doses at the same minute are combined into one unified alarm slot without clashing screens.
* **Alarm Screen Branding & Action Buttons**: Added Dosezy app branding header, "Reminder for:" patient subtitle, age & gender display, enlarged time string with alarm icon, squircle medicine image frames, dark-mode high-contrast card styling, and capitalized primary/secondary action buttons (`TAKE ALL` and `SNOOZE`).
* **Medicine Inventory & Stock Tracking**: Added full stock tracking with `Current Stock` and `Refill Threshold` fields across Add & Edit Medicine flows. Automatically deducts unit stock upon dose intake and displays dynamic refill warning badges with theme-tailored high contrast for light and dark modes.
* **Multi-Dose Presets & Precise Time Editing**: Added frequency preset selectors (`1x`, `2x`, `3x`, `4x` Daily) and enhanced custom time chips. Tapping an existing time chip (`⏰ 08:00 AM`) opens the time editor for that specific entry, clicking `+ Add Time` appends a new time slot, and tapping `✕` removes individual dose times.
* **Card Styling & Background Parity**: Re-styled medicine items on the **Medicines** page and all cards on the **Backup & Restore** page to match the exact **Home** screen card design language (`MaterialTheme.colorScheme.surface`, `RoundedCornerShape(12.dp)`, `shadowElevation = 4.dp`).
* **Backup & Restore Revamp**:
  - Reorganized into **"AUTOMATIC"** and **"MANUAL"** sections.
  - Added **Dosezy Cloud Server** card (marked COMING SOON with zero-knowledge multi-device sync details).
  - Added **Self-Hosted Server** card (marked COMING SOON with private Docker instance details).
  - Configured **Export Full Backup** with an upload icon and **Restore from Backup** with a download icon and full ZIP profile extraction dialog.
* **New User Screen & Import Source Dialog**:
  - Updated onboarding with a width-constrained **"Import from server/backup"** button.
  - Introduced the new **Import Source Dialog** featuring tabbed navigation between locked Cloud/Server sync and Local File backup selection.
* **Analytics Unified Single Card & ALL Tab**: Combined Hero Adherence and Multi-Range Breakdown into a single card with horizontal glance mini-rings, plus a dedicated `ALL` tab showing all timeframe rings above usage metadata.
* **Month-Wide Calendar Status Underlines**: Enhanced `ScheduleCalendar.kt` to render status indicator underlines across all visible days in the current month with enlarged `21.sp` font and squircle day selection bounds.
* **100% 12-Language Localization Parity**: Complete internationalization across all 12 supported languages (English, Arabic, Bengali, German, Spanish, French, Hindi, Italian, Japanese, Portuguese, Russian, Chinese) with 381 translated string keys and zero missing entries.
* **PDF Report Rendering Fixes**: Enabled anti-aliasing on PDF text drawing canvas to eliminate character distortion spacing, fixed taken-at timestamp formatting, and replaced 1970 epoch fallbacks with clean status labels.
* **Menu Navigation & Bottom Bar Polish**: Consolidated Data and Network items into a unified `Data & Sharing` section, updated FAQ descriptions, and wrapped `CustomNavigationBar` in a transparent surface to remove top background overflow.

## 🌐 Backend & API

* **OpenAPI 3.0 Inventory & Grouped Slot Schemas**: Updated `api/openapi.yaml` with schemas for stock inventory tracking, refill threshold alert endpoints, and slot-based grouped alarm payloads.
