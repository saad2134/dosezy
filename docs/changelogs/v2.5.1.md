# `v2.5.1`

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu → Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.5.1** APK.
> 4. Go to **Menu → Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

## 💊 Patient App (Android)

* **5-Second Safety Confirmation Timer**: Added an intentional 5-second countdown safety lock on permanent medicine deletion dialogs in both the active medicine editor and the archived medicine list, safeguarding against accidental data loss.
* **Accurate Adherence Analytics Baseline**: Fixed an issue where `0/61` was displayed immediately after adding a first medication before any doses were taken or missed; adherence now properly calculates against past decided doses and shows `0/0` (0%) when starting out.
* **Instant Language and RTL Switching**: Resolved an issue where subtitles required reopening screens to update and Arabic RTL alignment required an app relaunch; language selection now reloads the entire view hierarchy and switches layout direction immediately.
* **Comprehensive Multilingual Localization**: Localized emergency country names, cryptocurrency donation names, About screen headers, pharmacy refill order text, alarm pop-up overlay permission dialogs, and export error messages across all 12 supported locales.
* **Activity Report Export File Path**: The data export success dialog now shows the exported file name and full device storage path for easy file management.
* **Targeted Store Updates and Appteka Support**: Added support for the Appteka marketplace (`appteka.store`), and configured "Check for Updates" to explicitly launch the original installing store (Google Play, F-Droid, Appteka, etc.) directly without prompting the user with an "Open with" chooser.
* **Direct Battery Optimization Exemption**: Prompt directly for battery optimization exemption on aggressive OEM devices (such as Samsung) rather than opening general battery usage overview pages.
* **Reliable Notification Status Indicator**: Updated the Top Bar notification status button to alert users with a red indicator whenever the device is set to silent or vibrate mode.
* **Markdown Order Preview**: Renamed the pharmacy order preview label to Markdown Preview for clear formatting indication across all 12 supported languages.
* **Collapsible Cryptocurrency Support**: Merged cryptocurrency donation addresses into a single collapsible card under the Support Development section on the About screen.
* **Controlled Pharmacy Refill Form**: Added interactive quantity steppers (`[-] [Qty] [+]`) per medicine and a stock privacy toggle (`"Include current stock in message"`), allowing patients to order exact custom quantities and keep their home inventory private from chemists.
* **Persistent Emergency Country Selection**: The selected emergency country is now persistently saved in app preferences across app launches, while still providing smart automatic location detection for initial safety.
* **Streamlined Profile Dialog**: Removed the redundant and misaligned close button from the Profile Dialog in favor of intuitive outside-touch dismissal.
