# `v2.5.3`

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu → Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.5.3** APK.
> 4. Go to **Menu → Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

## 💊 Patient App (Android)

* **Critical Fix for Stock Auto-Decrement (Fixes Issue #80)**: Fixed a critical inventory tracking bug where clicking "Medication Taken" on medications whose strength was measured in milligrams (`mg`) or micrograms (`mcg`) deducted the dosage strength value (e.g. 150 or 700 units) directly from physical inventory count instead of 1 unit. This caused stock to immediately drop to 0 and trigger false low-stock refill alarms. Intake of solid medications now safely decrements exactly 1 unit (`medicationStock = medicationStock - 1`), with intelligent bounds for tablets, capsules, drops, and liquid volumes.
* **Intake Reversal Consistency**: Reverting a taken dose via Undo or as-needed logging also accurately restores the exact unit deduction amount.
* **Unit Testing Coverage**: Added test coverage verifying stock decrement calculations across all dosage units (`mg`, `mcg`, `tablet`, `capsule`, `drop`, `ml`).
