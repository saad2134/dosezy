# `v2.3.1`

## 💊 Patient App (Android)

* **Schedule Duplication on Medication Edit Fix**: Resolved an issue where modifying reminder times left behind stale, un-taken dose entries for the current day; all untaken doses from the start of the current day are now cleanly purged before new schedule slots are generated, while preserving already taken medication history.
* **Alarm Sound, Vibration & Wake-up Reliability**: Configured dedicated alarm notification channel attributes (`USAGE_ALARM`, `RingtoneManager.TYPE_ALARM`), high-priority vibration patterns, DND bypass, and CPU wake locks so that device ringtone, vibration, and full-screen alarm intents trigger reliably even when Android background activity starts are restricted.
* **Multi-Dose Frequency Presets Dynamic Wrapping**: Upgraded daily frequency preset chip selectors (`1x`, `2x`, `3x`, `4x` Daily) to `FlowRow` in both Add and Edit Medicine screens, enabling chips to wrap onto multiple lines cleanly on narrower screens without squishing label text or distorting chip dimensions.
* **Analytics Screen Responsive Layouts**:
  - Replaced the horizontal scrolling row in the top time range selector with a centered `FlowRow`, ensuring all period tabs remain accessible and wrap naturally on compact displays.
  - Upgraded the `ALL` tab period breakdown to wrap adherence mini-rings downward in a clean multi-row responsive flow rather than forcing horizontal scrolling.
* **Cloud/Server Coming Soon Badge UI Polish**: Redesigned the "COMING SOON" badge in the `ImportSourceDialog` on the New User screen using `FlowRow`, single-line text constraints (`maxLines = 1`, `softWrap = false`), and tighter vertical spacing to eliminate awkward multi-line word breaks and excessive line heights.
* **Stock & Refill Badge Localization**: Extracted and localized stock indicators (`⚠️ Refill Warning: %1$d left` and `📦 Stock: %1$d`) across the Home and Medicines screens.
* **Timing & Status Message Localization**: Localized all time calculation phrases (`To be taken in %1$dh %2$dm`, `%1$dh %2$dm ago`, `All medications taken`, `Scheduled for this time`) and screen section titles across all 12 supported languages.
* **100% 12-Language Localization Parity (389 Keys)**: Maintained full internationalization parity across all 12 supported locales (English, Arabic, Bengali, German, Spanish, French, Hindi, Italian, Japanese, Portuguese, Russian, Chinese) with 389 string keys each and zero missing entries.
