# `v2.4.4`

> **⚠️ Note for existing GitHub APK users**:
> Because Dosezy v2.4.2+ transitions to our official production release signing key (required for Google Play), updating directly over older debug-signed APKs requires a quick backup & reinstall:
> 1. In Dosezy, go to **Menu → Backup & Restore** and tap **Export/Create Backup**.
> 2. Uninstall the older version.
> 3. Install the new **v2.4.4** APK.
> 4. Go to **Menu → Backup & Restore** and tap **Restore Backup** to restore all profiles, medicines, and history in 1 tap.

---

## 💊 Patient App (Android)

* **Custom Device Audio File Picker**:
  - Added support for selecting any custom audio file (MP3, WAV, OGG, M4A, etc.) from device storage in **Menu → Preferences → Alarm Sound**.
  - Securely copies the chosen audio file into application internal storage so alarms trigger reliably even if the original download file is moved or deleted.
  - Added in-app live sound preview for custom audio files directly within the sound picker dialog.
* **Notification & Full-Screen Popup Reliability**:
  - Added `SYSTEM_ALERT_WINDOW` permission support and dedicated OEM background pop-up settings integration (Xiaomi HyperOS/MIUI, Samsung OneUI, OPPO ColorOS, Vivo FuntouchOS, Huawei EMUI).
  - Hardened notification channels with `AudioAttributes.USAGE_ALARM` to prevent OEM skins from suppressing full-screen alarm popups.
  - Revamped the Notification Status dialog with an all-in-one reliability checklist (Notifications, Exact Alarms, Display Over Apps, Battery Optimization, Sound, and 1-tap OEM device setup).
* **Schedule Invalidation for Finite Medications**:
  - Fixed schedule recalculation and immediate future cleanup when editing medication duration from ongoing to finite.
* **Database & Backup Compatibility**:
  - Added Room database migration 9 → 10 to store custom alarm sound paths and titles.
  - Included custom alarm sound metadata in data backup export and restore operations.
* **F-Droid Open-Source Compliance (#56)**:
  - Disabled `dependenciesInfo` metadata packaging in APK and App Bundle builds to remove proprietary `DependencyInfoBlock` signing blocks per F-Droid distribution standards.
