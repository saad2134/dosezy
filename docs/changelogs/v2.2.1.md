# `v2.2.1`

## 💊 Patient App 

### Android

* New Medication Analytics Screen: Track overall adherence percentage, doses taken on time vs late vs missed, past 7-day adherence trend, and active usage duration.
* Menu Navigation Enhancements: Added Analytics shortcut above Preferences, and placeholder indicators for upcoming Backup & Restore and Caregiver Sharing features.
* Enhanced Preferences Icons: Updated distinctive icons for Consider Late After, Consider Missed After, and Snooze Duration settings.
* Complete 12-Language Localization: Handcrafted translations for all new analytics and menu features across English, Spanish, Hindi, Chinese, Portuguese, Arabic, French, German, Japanese, Russian, Italian, and Bengali.
* Build & Performance Improvements: Version 2.2.1 release optimizations.

## 🌐 Website

- Add a new Next.js app in /website (bootstrapped with create-next-app). 
- Includes package.json + lock, tsconfig, next.config, ESLint & PostCSS configs, Tailwind setup, global CSS, favicon and SVG assets, and a large TypeScript page (src/app/page.tsx) implementing the Dosezy marketing/preview UI (screenshots carousel, interactive phone mockups, 12-language demos, FAQs, download CTA). Uses next@16, react@19, lucide-react, and TypeScript. Intended as the project website and interactive app preview.
