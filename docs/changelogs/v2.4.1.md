# `v2.4.1`

## 💊 Patient App (Android)

* **Configurable Alarm Ring Duration / Auto-Silence**:
  - Added user-configurable auto-silence timeout options (`30 seconds`, `1 minute`, `2 minutes`, `5 minutes`, or `Continuous (Until Dismissed)`) under Preferences.
  - Automatically silences audio and vibration after the selected duration if the user cannot immediately reach their phone (e.g. while cooking, driving, or away from the device), while keeping the interactive full-screen dose checklist on screen for when they return.
  - Seamlessly integrates with follow-up nagging reminders if scheduled doses remain unconfirmed.
* **Database Migration & Backup Compatibility**:
  - Upgraded Room schema to version 9 with non-destructive migration (`MIGRATION_8_9`) preserving existing user preferences and data.
  - Updated JSON health report and ZIP backup restore handlers to support `alarmDurationSeconds`.
* **100% 12-Language Localization Parity**:
  - Added complete localization across all 12 supported languages (English, Spanish, French, German, Italian, Portuguese, Russian, Chinese, Japanese, Hindi, Bengali, Arabic).
