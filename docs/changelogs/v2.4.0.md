# `v2.4.0`

## 💊 Patient App (Android)

* **Custom Alarm Sounds (4 Custom Synthesized Sounds + System Default)**:
  - Added 4 high-clarity synthesized alarm tones (`Gentle Chime`, `Medical Marimba`, `Brisk Pulse`, `Calm Bell`) alongside the device's System Default.
  - Easily selectable in user Preferences with 1-tap interactive preview playback.
  - Full-screen alarm alarms seamlessly stream custom audio in loops or default to system ringtones.
* **Allergies & Medical Conditions in Profiles (#50)**:
  - Users can now document their known drug/food allergies (e.g. Penicillin, Sulfa, Peanuts) and chronic medical conditions (e.g. Hypertension, Type 2 Diabetes) during onboarding and profile management.
  - Prominently displays vital medical data on the Emergency Screen for first responders and caregivers.
  - Automatically incorporates patient allergies and chronic conditions in generated Doctor PDF and CSV/JSON export files.
* **Follow-Up / Nagging Reminders (#49)**:
  - Configurable persistent nagging reminders in user Preferences (`5 min`, `10 min`, `15 min`, etc.) with customizable repeat counts (1 to 5 times) to alert users if a scheduled dose has not been marked as taken.
  - Automatically cancels repeated reminders upon dose confirmation or snoozing.
* **Home Screen Widget (#48)**:
  - Added an interactive Android Home Screen App Widget (`Dosezy Today`) providing real-time dose counters, today's adherence progress, and next scheduled medicine info with one-tap launcher access to the app.
* **One-Tap "Refill Stock" Quick Action (#47)**:
  - Quick refill button directly on medication cards with intuitive presets (`+30`, `+60`, `+90`) and custom quantity input, eliminating the need to edit the entire prescription to restock medicines.
* **Doctor & Pharmacy Notes / Special Warnings (#46)**:
  - Added dedicated notes field to store instructions (e.g. "Take with food", "Avoid grapefruit", Rx prescription numbers) with visual warning badges and doctor notes preview on Home and Medicines lists.
* **Color & Shape Icon Selector (#45)**:
  - Visual medication selector with 8 vector pill shapes (`Round`, `Capsule`, `Oval`, `Liquid`, `Inhaler`, `Injection`, `Drops`, `Patch`) and a rich 10-color visual palette for instant identification without uploading custom photos.
* **Interval-Based Scheduling (#44)**:
  - Introduced flexible interval scheduling patterns supporting `Every X Hours` and `Every X Days` with automatic next-dose generation.
* **Prescription End Dates & Finite Courses (#43)**:
  - Support for fixed treatment durations (e.g. 7-day or 10-day antibiotic courses) with automatic completion badges, schedule boundary enforcement, and clear course progress tracking.
* **"As Needed" (PRN) Medications (#42)**:
  - Support for PRN medications without fixed alarms, featuring dedicated on-demand dose logging with auto-decrement stock integration and daily dose history counters.
* **Medication Archival & Soft-Delete (Room DB v8)**:
  - Stop finished treatments without losing historical dose records, adherence statistics, or PDF report history via a dedicated "Discontinue (Keep History)" action.
  - Discontinued medications are organized in a collapsible section on the Medicines screen with a 1-tap "Reactivate" button.
* **About Dosezy & Multi-Channel Open-Source Donations**:
  - Added a dedicated "About Dosezy" screen with app branding, versioning, GitHub Star shortcut, GitHub Sponsors, Buy Me a Coffee, and 1-tap copy cryptocurrency wallet cards with automated wallet app intent launching (Bitcoin, Ethereum, Solana, Litecoin, Zcash).
* **Help & Support Polish & GitHub Issues**:
  - Cleaned section spacing and added a direct "Report an Issue" card linking to GitHub Issues.
* **Menu Page & TopBar UI Polish**:
  - Eliminated unwanted empty padding between the TopBar, Menu cards, and Bottom Navigation bar.
  - Reordered Cloud Setup badges to `Optional`, `Soon` and trimmed unnecessary badges.
  - Protected TopBar action buttons against compression when rendering long user profile names.
* **100% 12-Language Localization Parity**:
  - Full translation parity across all 12 supported languages (English, Spanish, Hindi, Chinese, Portuguese, Arabic, French, German, Japanese, Russian, Italian, Bengali) covering all new v2.4.0 features and alarm sound labels.
* **Database & Backup Migration**:
  - Upgraded Room schema to version 8 with non-destructive migrations and complete backup/restore JSON & ZIP compatibility.
