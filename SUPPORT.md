# Support

Thank you for using **Dosezy**.

Dosezy is an open-source Android medicine tracking and medication adherence application designed to make medication management simpler, more accessible, and easier to manage for individuals, families, elderly users, and caregivers.

If you need help using Dosezy, please use the appropriate channel below.

---

## 🆘 Getting Help

### 📖 Documentation

Start with the project's README and documentation for information about:

* Installing Dosezy
* Building Dosezy from source
* Using medication reminders
* Managing medication schedules
* Managing multiple profiles
* Exporting data
* Accessibility features
* Development and contribution

Repository:

https://github.com/saad2134/dosezy

## 🐛 Bug Reports

If you believe you have found a bug, please search the existing GitHub Issues first.

If the problem has not already been reported, open a new issue with:

* A clear description of the problem
* Steps to reproduce it
* Expected behavior
* Actual behavior
* Dosezy version
* Android version
* Device model
* Relevant screenshots or recordings
* Relevant logs or error messages, when available

Please avoid posting private medical information, personal information, credentials, API keys, or other sensitive data in public issues.

GitHub Issues:

https://github.com/saad2134/dosezy/issues

---

## 💡 Feature Requests

Feature requests are welcome.

Before opening a new request, please search existing issues and discussions to see whether the idea has already been proposed.

A useful feature request should explain:

1. What problem the feature would solve.
2. Who would benefit from it.
3. How you expect it to work.
4. Any relevant accessibility, privacy, offline-use, or usability considerations.

## 🩺 Medical Disclaimer

Dosezy is a software tool for medication tracking, scheduling, reminders, and adherence support.

Dosezy does **not** provide medical advice, diagnosis, treatment recommendations, or professional healthcare services.

Users should follow the instructions provided by their healthcare professionals and medication labels. Dosezy should not be relied upon as a substitute for professional medical advice or emergency medical care.

If you believe you are experiencing a medical emergency, contact the appropriate local emergency service or a qualified healthcare professional.
