We actively support and provide security updates for the following versions of Dosezy:

| Version | Supported          |
| ------- | ------------------ |
| 2.2.x   | :white_check_mark: |
| 2.1.x   | :white_check_mark: |
| < 2.1.0 | :x:                |

---

## Reporting a Vulnerability

The Dosezy team and community take the security and privacy of our users very seriously. If you believe you have found a security vulnerability in any part of Dosezy (Android Patient App, Marketing Website, or future Caregiver Cloud Platform), please report it to us responsibly.

### How to Report

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send a detailed report via email to:

📧 **[reach.saad@outlook.com](mailto:reach.saad@outlook.com)**

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:
* A clear description of the vulnerability and its potential impact.
* Steps to reproduce the issue (proof-of-concept code, scripts, or screenshots where applicable).
* The affected component and version (e.g., `patient/android v2.2.1`).
* Any proposed mitigations or fixes, if available.

### Response & Disclosure Process

* **Acknowledgment:** We will acknowledge receipt of your vulnerability report within **48 hours**.
* **Assessment & Fix:** We will investigate and provide regular updates on our progress toward a fix or mitigation.
* **Responsible Disclosure:** Once a fix has been verified and released in an updated version, we will coordinate public disclosure and gladly credit your responsible reporting.

Thank you for helping keep Dosezy safe and private for everyone!
